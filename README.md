# pipelinek-acp

Reactive Agentic Pipelines for [PipelineK](https://github.com/Rubentxu/pipeline-kotlin): an ACP-client plugin that lets a Kotlin pipeline drive an external agent over the Agent Client Protocol, react to typed agent events, and expose its own steps as MCP tools.

- Backlog (autoridad única, living in [pipelinek-home](https://github.com/Rubentxu/pipelinek-home)): filter tasks by label `repo:pipelinek-acp`; SDK contracts carry `repo:pipeline-kotlin`.
- Status: the plugin ships five steps — `acpPrompt` (one delegation), `acpTask` (an isolated delegation under a profile), `acpSession` (a composed session: several sequential turns plus the negotiated session operations), `acpReactive` (one delegation that reacts to the agent's updates: `acpOn(id, selector)` names a body child per declared reaction — static slot addresses, serializable data, never runtime lambdas — and `acpAwait(selector, timeout)` answers inside the turn; an empty declaration keeps the shipped unnamed slot, once per update, each dispatch with its own durable identity) and `acpReaction` (the body child it dispatches). The intake tasks are on the home board; the work is tracked there.
- Reconciliation (SDK contracts PKACP-SDK-03/04, over the existing durable journal): a reactive turn dispatches under an intent/ack ledger whose rows ride in the step's own durable output (`reactionLedger`) — no second store of runs exists and none is opened. Each event is addressed by an `EventKey`: the agent's external id when the run vouches for its source, the persisted per-connection nonce plus cursor otherwise; an event with neither fails closed on a journalled run. A crash between intent and ack is the honest `UNKNOWN` and is never re-driven automatically, and **exactly-once for external effects is not promised** without idempotency proven at the remote. On reload/reconnect dedupe compares keys, never the renumbered cursors; replayed `session/load` history never re-fires an effectful reaction, and where history and live cannot be told apart the effectful reactions suspend until the run reconciles. Operators `acpTake(limit)`, `acpDistinct()` and `acpDebounce(windowMillis)` (the last only on a `coalescible` reaction, every one of them bounded and clock-injected so a replay reproduces its verdicts) limit dispatches, and a permission request is never discarded by any of them.
- Human interaction: the steps that can be asked by the agent for a person's input declare the human-decision capability and put the question to a person through the port the published SDK carries; the person's answer reaches the agent and grants nothing — a permission is still the declared authority's to decide.
- Build: this project compiles with JDK 21, declared once in `gradle.properties` (`pipelinek.acp.jvmToolchain`). Kotlin compiles inside the Gradle daemon, so the daemon's JDK is the JDK that compiles — the build refuses any other one, naming the JDK it expects, the JDK it found and the path that fixes it (`gradle/jdk-guard.gradle`).
- Observability (SDK contract PKACP-SDK-04): `acpPrompt`, `acpSession`, `acpTask` and `acpReactive` project typed ACP facts (`pipelinek.acp.*`) into PipelineK's observability through the published seam — an `EventDefinitionContributor` contributes the manifest's kinds and the `plugin.event-emission` capability emits them; never the wire's JSON-RPC. The payload is redacted field by field under a whitelist (no `rawInput`, no `rawOutput`, no `_meta`, no raw JSON of an unknown variant; URIs are reduced to scheme/host/path — no userinfo, query or fragment; text is clipped and the clip is marked) and the lane is bounded: control facts survive a chunk avalanche and every telemetry loss is counted in an `observation_gap`. The lifecycle facts the plugin establishes itself are published from the real exchange path — `exchange_started` once the negotiation held, `turn_ended` per turn with the agent's stop reason, `exchange_cancelled` when the budget or the engine cuts the exchange (said together with the `session/cancel` the agent receives), `exchange_refused` with the typed refusal's kindToken — and the task e2e row (`scripts/e2e-acp-task.sh`, LIFECYCLE) measures all four against the durable events table, the cancelled one under a deliberate chunk avalanche. Reverse-leg notifications the SDK delivers outside the prompt stream reach the same projection, without giving up their journal row.

CI is PipelineK running locally (`pipeline.kts`), not GitHub Actions.
